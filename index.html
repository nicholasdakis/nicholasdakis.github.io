Projects

Level Up!

Health tracking app for food, water, weight, workouts and habits, with XP, streaks and challenges.

  • Android
  • Web (PWA)

Features

  • Log meals via barcode scan, search (typed or speech-to-text), manual entry, or saved meal templates, with macro and micronutrient breakdown
  • Track workouts with sets, reps, weight, live and rest timers, and personal record (PR) alerts; active sessions survive the app closing
  • Create workout routines, or browse and save public ones
  • Check in to nearby points of interest on a map to earn XP
  • Leaderboards and achievement badges
  • Daily rewards with streak multipliers
  • Reminders through push notifications
  • Track habits with consistency scoring and per-habit streaks
  • Friend system with activity feed, nudges, and privacy controls
  • Daily, weekly, and global challenges with shared progress
  • Analytics for food, workouts, water and weight
  • Shareable stat and recap cards
  • Optional Pro subscription

Technical details

  • Flask backend split into route, service and repository layers; every user route checks the Firebase token
  • PL/pgSQL functions with row-level locking for XP and reward updates
  • The PL/pgSQL functions are tested in CI against a temporary PostgreSQL database
  • Row-level security is on for every table; only the backend's service key can access the data
  • Redis cache for food search, with a per-query lock to prevent cache stampedes
  • Daily quota on food API calls; a failed call doesn't count against the quota
  • Push notifications through FCM; invalid device tokens are removed automatically
  • GitHub Actions runs the pytest and Flutter test suites and deploys the web app only if both pass
